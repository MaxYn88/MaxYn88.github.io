01Research software · Jun 2025 to Aug 2026

Mouse Gait Analysis Pipeline

Tissue Biomechanics Laboratory, UIUC

A four-stage Python pipeline that turns raw video of a walking mouse into gait metrics, translated from the lab's MATLAB workflow. Co-developed with one other researcher.

  1. 1EnhanceCLAHE contrast correction with OpenCV
  2. 2TrackGPU-accelerated pose estimation with DeepLabCut
  3. 3CleanConfidence and jump filtering, lens-distortion correction, cubic interpolation
  4. 4MeasureGait metrics in MATLAB, called from Python through the MATLAB Engine API
60% → 78%missing-keypoint recovery
120videos processed
12animals

What I did

  • Designed the keypoint filtering, lens-distortion correction and cubic interpolation, raising missing-keypoint recovery from 60% to 78%.
  • Tracked down a cross-language shape mismatch between the Python and MATLAB stages, then validated pipeline output across experimental cohorts.
  • Automated extraction and plotting of stride length, stance and swing duration, and bout counts with pandas and Matplotlib.
